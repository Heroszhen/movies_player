---grumphp
C'est un outil qui va intercepter tes commits Git (via ce qu'on appelle des hooks Git) et analyser ton code avant qu'il ne soit validé et envoyé sur le dépôt distant.

composer require --dev phpro/grumphp

vendor/bin/grumphp run
ou 
winpty php vendor/bin/grumphp run (sur windows)
